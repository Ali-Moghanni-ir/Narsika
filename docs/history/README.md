# Engineering history

These documents are the review, validation and change reports written while Narsika's Public Beta was built (September 2026). They are kept unchanged for traceability: they explain *why* many decisions were made and record the test evidence available at the time.

They are **not** current documentation. Commands, test counts and limitations in them may be out of date, and several are written in Persian. For current information, start at the [documentation index](../README.md).
